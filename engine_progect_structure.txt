ТЕХНІЧНИЙ ОПИС АРХІТЕКТУРИ KVM ENGINE

Проєкт реалізує систему IP-KVM (Keyboard, Video, Mouse) на базі вбудованих Linux-систем. Архітектура розділена на три рівні: Video Pipeline (C++/V4L2), HID Server (Go/WebSockets) та System Orchestration (Bash/ConfigFS).

D:\diplom\kvm_engine\
├───config\
│   ├───config.json — Головний файл конфігурації параметрів відео (FPS, бітрейт) та мережевих портів.
│   └───mediamtx.yml — Конфігурація RTSP/WebRTC сервера MediaMTX для трансляції відеопотоку.
├───scripts\
│   ├───go.mod — Файл опису модуля Go та залежностей для допоміжних скриптів тестування.
│   ├───init_kvm.sh — Налаштовує відео-міст TC358743: завантажує EDID, встановлює таймінги та формат пікселів через v4l2-ctl.
│   ├───setup_usb_gadget.sh — Конфігурує ядро Linux для роботи у режимі USB-гаджета (Keyboard + Mouse) через інтерфейс ConfigFS.
│   ├───start_kvm.sh — Головний оркестратор, що ініціалізує апаратну частину, збирає компоненти та запускає всі сервіси системи.
│   ├───test_keyboard.go — Утиліта на Go для прямої перевірки запису HID-репортів у символьний пристрій /dev/hidg0.
│   └───wake_host.sh — Реалізує пробудження хост-ПК через низькорівневий протокол USB SRP або імітацію натискання клавіш.
└───src\
    ├───CaptureDevice.cpp — Реалізація методів захвату відео: робота з чергами V4L2-буферів та експорт DMABUF для енкодера.
    ├───CaptureDevice.hpp — Оголошення класу CaptureDevice, що відповідає за низькорівневий інтерфейс із HDMI-Capture картою.
    ├───Config.cpp — Логіка завантаження та валідації JSON-конфігурації за допомогою бібліотеки nlohmann/json.
    ├───Config.hpp — Визначення структур даних для налаштувань відеопотоку, енкодера та параметрів HID-сервера.
    ├───EncoderDevice.cpp — Реалізація взаємодії з апаратним кодером H.264 (V4L2 M2M): налаштування бітрейту, GOP та профілів.
    ├───EncoderDevice.hpp — Опис класу EncoderDevice для керування процесом стиснення сирого відеопотоку у H.264.
    ├───main.cpp — Точка входу C++ двигуна: реалізує подієво-орієнтований цикл poll() для синхронізації захвату та кодування кадрів.
    └───hid_server\
        ├───go.mod — Визначення модуля Go та залежностей (gorilla/websocket) для сервера керування.
        └───main.go — WebSocket-сервер, що транслює мережеві команди у фізичні USB HID репорти через пристрої /dev/hidg*.
